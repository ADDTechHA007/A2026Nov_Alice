本手册用于同事试走订单流程。实际操作以真实业务进展和凭证为依据；测试时建议使用 DEMO 演示订单。一个 Invoice 建立一份订单档案，其中每项产品独立选择制作方式、审批和推进。同一订单的一个产品完成，不代表整张订单完成。

1. 开始使用与页面位置

在工作台电脑双击“启动工作台.cmd”，打开 订单工作台。已经打开时直接使用，不必重复启动。

当前测试可在右上角“演示角色”选择“审核”，连续体验所有环节，无须反复切换身份。历史记录仍记为审核。必填检查、节点顺序、老板批准后的锁定规则继续生效。角色切换只是测试功能，尚未建立真实人员登录和权限。

先在左侧选择 Invoice，再在订单上方选择要处理的产品。进行每次操作前，确认产品名称、产品编号和当前节点。

页面位置用来做什么
左侧订单列表与搜索按 Invoice 或客户找订单
我的待办、资料尚未齐全、等待老板审批筛选需要处理的产品；审核测试模式的待办包含各环节未完成产品
产品标签切换同一订单下的不同产品
产品流程进度条查看当前节点及前后流程
资料与进度填制作类型、执行资料、上传凭证及确认交接
Invoice 与来源查看导入文件、截图、原始售价及金额核对；仅导入订单显示
邮件档案查看审批邮件、生成业务邮件、下载含附件草稿
海运批次登记船名、航次、提单、分批数量及确认到货
操作历史查看修改、审批、退回、凭证及交接记录
页面顶部或侧栏的工作台手册打开本说明

保存提醒：切换订单、产品、角色、页签或刷新页面前，先保存当前填写。工作台尚无全局自动保存；不要把未保存输入当成已登记资料。

2. 导入 Invoice

常规由销售或财务导入；当前审核测试角色也可以导入。

  1. 点击右上角“导入 Invoice”。
  2. 选择 QuickBooks 原始 Invoice PDF，或产品明细 XLS / UTF-8 CSV 文件。
  3. 点击“读取并预览产品”，核对产品、数量、销售单价及行金额。
  4. PDF 会填入识别到的 Invoice 编号、客户候选名称、日期和税率，逐项与原件核对。XLS / CSV 缺少这些信息时须补填。
  5. 可填发票日期、付款到期日、销售币种和统一销售税率；未知留空。
  6. 可附 Invoice 截图或其他来源文件。
  7. PDF 须勾选已核对识别结果和全部提示，再点击“确认导入，交销售补充”。所有产品进入“制作类型待补充”。

XLS / CSV 产品表头须为：PRODUCT/SERVICE, DESCRIPTION, QUANTITY, RATE, AMOUNT, SALES TAX。本版支持1至50项产品及整数数量，并核对数量乘以售价是否等于行金额。单个来源文件最大10MB，可额外附5个来源文件，总量最大20MB。

PDF 支持可复制文字的 QuickBooks 发票同版式（Bill to、Ship to、Invoice #、Description / Qty / Rate / Tax / Amount），最多10页。解析器会核对每行金额、小计、税额及总额；不支持的版式、无法归属的跨页说明、折扣等无法核对的金额会停止导入，改用 XLS / CSV。扫描件和截图不自动识别。

PDF 日期如 05/11/2026 有日月歧义，先按 QuickBooks 实际设置选择“日/月/年”或“月/日/年”，再重新读取。保留原日期文字，不能根据 Invoice 编号推算日期。描述 Qty 与数量栏不一致时会提醒，导入采用数量栏并保留完整描述。PDF 只显示 $ 时，币种不会自动推断。

PDF 原件随订单保存，Bill to / Ship to、付款条款、原 Ship date、Ship via、Tracking、REP、PO 及识别提示可在“Invoice 与来源”查看。REP 可填入销售负责人；Ship date 不作交货要求，原 Tracking 不自动建立海运批次，TOTAL DUE 不作付款到期日。未显示的付款日期仍留空。

统一税率只适用于所有行采用相同税率的未税金额。PDF 保留原税额及合计；若手填税率计算值与 PDF 不符会提示核对。混合税率可保留原税额而将统一税率留空。截图作为原件归档，不自动识别内容。

同一 Invoice 编号不能重复建档，已有订单应打开原档案。无导出文件时可点“手动录入”，后续仍按产品补制作类型。

字段区别：Invoice RATE 是销售单价，不是采购成本；付款到期日不是要求交货日期。文件导入不会自动回写 QuickBooks，也不代表已收付款、已确认库存或已发货。

3. 逐项选择制作类型

位置：选择产品 → “资料与进度” → 顶部制作类型区域。

填写销售负责人、选择制作类型，可补制作备注，然后点“保存制作类型”。销售负责人由整张订单共用；类型和备注按产品单独保存。名称中的 In Stock、SKU、印刷描述和售价不会自动替同事选择制作方式。

制作类型适用情况备注示例保存后进入
国内定制需要向国内工厂采购、定制或生产拟交工厂A，按图稿V2；生产周期及海运安排待确认待补资料
本地库存直发使用本地库存，无须加工，直接交付无须印刷；库存待仓库核实；客户拟自提库存预留
本地库存加工使用本地库存，还需本地印刷或其他加工白色袋单面黑色Logo；加工商和库存待确认待补资料

三张说明卡片未选中时均为绿色；当前选中项为蓝色，显示“✓ 已选中”。下拉切换会即时改变高亮，点保存后才写入档案。系统其他位置可能使用“本地直发”“本地加工”简称。

制作备注写已确认安排、特殊要求及待确认问题；未知写“待确认”。备注不是库存确认，也不能代替附件或审批。类型尚不确定时先保留“制作类型待补充”，不推进业务。

老板批准前且尚未进入执行，可在允许节点更改类型；更改已选类型须填原因，新流程从起点开始，原记录保留。已有工厂业务草稿或运输记录时不能直接改类型。老板批准后制作类型及制作备注锁定。

4. 填产品资料与上传附件

位置：“资料与进度” → “产品与执行资料”。

内容填写规则
产品名称、订购数量名称清楚；数量为正整数
要求交货实际要求日期；未知可留空，不用付款到期日代替
工厂／加工商／仓库国内定制和本地加工须填写供应商
收件邮箱此处是工厂或加工商的业务邮箱，不是审批人邮箱
采购／加工单价、币种国内定制和本地加工单价须大于0；按实际币种填，与售价分开
规格／加工要求填尺寸、材质、印刷、图稿版本等，必须有产品规格文字
执行备注用于后续安排和沟通，保存后单独留痕

点“保存修改”保存执行资料。右侧审核清单按已保存数据检查；输入后出现“有未保存修改”时，清单可能仍显示旧缺项。直接点推进按钮也会先保存当前执行资料再检查，但制作类型区域仍须单独点“保存制作类型”。

上传统一入口：选择正确产品 → “资料与进度” → 右侧“归档附件” → “＋ 添加” → 选择资料类别 → 选择文件 → “保存并归档”。小屏幕中归档附件区可能在执行表单上方，找不到时向上滚动。

资料类别何时用当前规则
图稿/规格产品图稿、规格文件可选；未附在提交审核时弹窗提醒，可确认继续
工厂报价国内工厂报价依据可选；未附在提交审核时弹窗提醒，可确认继续
加工说明本地加工要求或委托说明本地加工审核前必填附件
工厂确认工厂接单回复、确认书、邮件截图确认工厂已接单前必须上传
付款凭证定金、尾款或其他付款记录可归档；目前没有独立付款校验节点
运输单据装箱、提单或其他运输凭证可归档；不能替代海运批次数量登记
出库凭证本地交付、提货或发货依据本地待发货完成前必须上传
其他其他补充依据按实际内容归档并注明用途

单个产品附件最大10MB。文件形成新记录，不覆盖旧文件。Invoice 共用来源可以在各产品中查看，但不会自动算作某个产品的“工厂确认”或其他指定类别。系统检查类别，内容仍须同事核对。

5. 三条流程与人员分工

下面列出当前三条流程；服务在线时此处显示各节点负责人。

国内定制：导入 Invoice → 制作类型待补充 → 待补资料 → 财务审核 → 老板审批 → 待下单 → 等工厂确认 → 生产中 → 待海运 → 海运中 → 已完成。

本地库存直发：导入 Invoice → 制作类型待补充 → 库存预留 → 待发货 → 已完成。

本地库存加工：导入 Invoice → 制作类型待补充 → 待补资料 → 财务审核 → 老板审批 → 待送加工 → 加工中 → 待发货 → 已完成。

本地库存直发在当前规则下不经过审核和老板审批。国内定制目前以全数海运到货作为该产品完成点，尚未纳入后续客户末端配送。

常规负责人主要工作
销售导入、逐项选类型、补产品要求及采购/加工资料
审核核对来源、数量、规格、供应商和成本；通过或退回
老板批准或退回当前版本资料
跟单工厂下单、回复归档、接单确认、生产跟进、本地加工验收
仓库库存预留、送加工、本地发货及出库凭证
物流海运批次、运输资料及逐批到货确认
财务Invoice 导入、收付款核对及付款凭证归档；完整记账与成本核算暂在现有工具完成

“财务审核”节点在本原型中由“审核”角色负责；“财务”是另一个演示角色。测试使用审核全权限不代表正式上线时由同一个人完成所有工作。

6. 提交审核与老板审批

第一步，提交审核：在“待补资料”节点核对资料，在底部交接输入框填写本次说明，点击“资料齐全，提交审核”。

若缺必填字段或本地加工说明，系统提示补齐。若只缺可选图稿/规格、工厂报价，会弹窗列出，选择“返回补充”或“仍然提交”。继续后进入审批邮件准备窗口。

每次都须填写本次审批人邮箱。窗口显示邮件正文，固定附本次资料摘要 approval-summary.txt；产品附件和订单 Invoice 来源默认勾选，可调整，合计最大20MB。检查后点“提交审批并准备邮件”。取消窗口不推进审批。

确认后产品进入“财务审核”，邮件保存为待发送草稿。下载 .eml，检查后手动发送。准备邮件和进入节点不代表邮件已送达，也不代表已通过。

第二步，审核交老板：审核人员查看“Invoice 与来源”、执行资料和附件；无误时点“审核通过，交老板审批”，再次填写这次老板邮箱、检查邮件及附件，再提交。产品进入“老板审批”。有问题则写明原因，点“退回补充”。

第三步，老板决定：当前测试可以在工作台直接点“批准，交接执行”，或测试新邮件中的免登录链接。退回时必须填原因。批准后国内定制进入“待下单”，本地加工进入“待送加工”。

邮件审批方案：保留演示，外网接入以后再定

新准备的老板审批邮件含“查看并审批”按钮和专属链接。打开后查看本次资料，明确选择批准或退回，勾选确认后提交，系统记录结果。仅打开邮件或链接不会批准。

链接7天有效，绑定产品、资料版本和当前节点；已处理、资料变更或重新生成新申请后，旧链接不能再审批。退回必须写原因。此版凭持有链接授权，未独立验证邮箱身份，请勿转发。

当前仍是本机演示：老板在外部手机或其他电脑尚不能打开 127.0.0.1。Yahoo 与销售的 GoDaddy/Outlook 邮箱继续保留，自动发信及外网 HTTPS 审批服务均暂不接入。

已有申请停在“老板审批”时，可点“重新准备老板审批邮件”，重新填写邮箱生成新草稿，不推进节点。旧邮件不会自动增加链接，未处理的旧链接会失效。

7. 老板批准后的锁定

老板批准后，制作类型、制作备注、产品名称、数量、交货要求、规格、供应商、业务邮箱、单价及币种均锁定。图稿/规格、工厂报价、加工说明类别也不能追加变更。审核测试权限同样不能绕过锁定。

订单中只要有一项产品获批，共用销售负责人就锁定。其他尚未批准的产品仍按自身状态处理。

后续仍可“保存执行备注”，或新增工厂确认、付款凭证、运输单据、出库凭证等执行材料，不改变已批准资料版本。已完成产品冻结。若批准后业务需要改数量或规格，当前没有解锁/变更申请功能，请先线下核实并记录问题，不用备注假装更改原审批内容。

老板批准前修改关键资料，或补新版规格、报价、加工说明，可能退回“待补资料”，需要重新审核；原记录继续保留。

8. 国内定制：下单、接单与生产

待下单：先发邮件，再确认发送

  1. 进入该产品的“邮件档案”，点击“生成邮件草稿”。
  2. 核对工厂收件邮箱、主题、数量、规格、价格、币种和交期，选择所需产品附件。
  3. 点击“保存邮件草稿”，下载 .eml。草稿生成不代表已发出。
  4. 用支持的邮件客户端检查并实际发送；若 .eml 无法作为草稿使用，可复制正文、下载附件，在现有 Outlook 中重新组成邮件。回复主题保留产品编号以便追踪。
  5. 返回“资料与进度”底部交接框，填写实际发送说明，例如“已向工厂A发送采购邮件，100个，单价3.5 CNY，附规格V2，等待确认”。
  6. 点击“已手动发送，等待工厂确认”，进入“等工厂确认”。必须先有当前版本的工厂业务邮件草稿；审批邮件不能代替工厂下单邮件。

等工厂确认：上传回复后再确认接单

工厂通过现有邮件回复。跟单核实工厂已明确接受产品、数量、价格和交期；涉及定金或其他付款条件的，需另外核实并归档依据。

位置：“资料与进度” → “归档附件” → “＋ 添加” → 类别选“工厂确认” → 上传回复邮件、截图或确认文件 → “保存并归档”。

再到底部填写确认说明，点击“确认工厂已接单”，进入“生产中”。仅填写“确认接单”文字不替代工厂确认附件。当前不自动读取工厂邮箱，也没有工厂接单链接。

生产中：跟进实际生产

生产进度、预计完成和沟通情况可用执行备注或“留下备注”记录；需要时上传相关凭证。确实生产完成后，在底部填写交接情况，点击“生产完成，交接物流”，进入“待海运”。

9. 国内定制：海运登记与到货

登记入口是“海运批次”页签，船号和到货数量不是填在底部交接说明框。

  1. 产品在“待海运”或“海运中”时，切换到“海运批次”。
  2. 点击“登记海运批次”，填写本批数量、船名、航次、提单号、开船日期和预计到港日期。
  3. 点击“保存海运批次”。一个产品可分多批，累计数量不得超过订购数量；预计到港不能早于开船日期。
  4. 至少登记一批后，返回“资料与进度”，点“进入海运跟踪”，产品进入“海运中”。
  5. 每批实际到货后，进入“海运批次”，找到该批并点“确认该批次已到货”。不要把预计到港日期当作已到货。
  6. 全部订购数量都登记且确认到货后，返回“资料与进度”，点“全部到货，完成产品”。

例如订购100个，可登记60个和40个两批。确认第一批后已到货60/100，仍不能完成；第二批也确认到货后才是100/100。提示“已到货0/100”时，先检查批次是否登记、是否逐批点了到货确认。

运输单据从“归档附件”上传，海运数量从“海运批次”登记，两者用途不同。当前批次不能在页面直接修改或删除；录错时先暂停确认并联系维护人员核实，勿重复登记凑数。跨订单合并装柜、货代独立门户及自动物流跟踪暂未实现。

10. 本地库存直发

  1. 类型保存为本地库存直发后进入“库存预留”。
  2. 仓库在实际库存中核实并预留，底部交接框写明数量、库位或提货安排，点“库存已预留，准备发货”。
  3. 产品进入“待发货”。实际交付后，通过“归档附件”上传“出库凭证”。
  4. 回到底部填写发货说明，点“确认已发货，完成产品”。

这条流程当前不经过审核和老板审批，也不登记海运。本机工作台只记录动作，不自动扣减库存；库存是否足够仍由仓库核实。

11. 本地库存加工

  1. 补产品规格、加工商、业务邮箱、采购/加工单价及币种，并上传“加工说明”；图稿/规格附件可选。
  2. 依次完成审核和老板审批，批准后进入“待送加工”。
  3. 仓库实际送交加工后，在底部写交接说明，点“确认已送加工”，进入“加工中”。
  4. 跟单核实加工完成并验收，在底部写验收结果，点“加工验收完成，准备发货”。
  5. 在“待发货”上传“出库凭证”，实际发货后点“确认已发货，完成产品”。

加工要求、数量、价格等在老板批准后锁定。此流程没有单独海运节点。

位置用途如何保存

14. 历史、导出及保存

“操作历史”可查看记录人、时间、修改前后内容、审批依据、退回原因及节点交接。审批邮件和业务邮件的正文、收件人、附件清单及版本在“邮件档案”保留。只生成草稿不算已发送；老板链接审批的结果会另行记入历史。

刷新页面、服务重启后，已保存数据仍在。左侧“导出订单与附件”导出当前工作台全部订单的数据 JSON、附件和邮件 ZIP，供存档，当前没有 ZIP 导入恢复按钮。导出中可能含真实客户资料及尚有效的审批链接，请只交给相关同事。

维护人员做可恢复备份时，先停止服务，再复制整个 data 目录；不要只复制运行中的单个 SQLite 主文件。当前记录是应用追加历史，本机有数据库文件权限的人仍能修改数据，不能作为防篡改审计系统。
